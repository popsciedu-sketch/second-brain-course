Logseq 實作：從安裝到 Query

按下列步驟建立一個小型「第二大腦」練習庫。可下載練習資料包匯入或對照輸入。每步附預期畫面示意（自製 UI 示意，非官方截圖）。

練習資料

路徑：assets/practice-data/ · 內含示例 Markdown 與 zip。清單見 DRIVE_UPLOAD_MANIFEST.md。

下載練習包（本地） Google Drive 練習包 Drive 資料夾

下載並安裝 Logseq

前往 logseq.com 下載桌面版（Windows／macOS／Linux）。安裝後開啟應用程式。亦可先用瀏覽器版體驗，但本教程以本地 graph 資料夾為準，方便備份與傳承。

Welcome to Logseq [ Add local graph ] [ Clone from Git ]

建立本地 Graph

選擇「Add local graph」，新建資料夾例如 SecondBrain-Practice。這就是你的大腦皮層檔案根目錄——全是明文 Markdown／資料檔，利於繼承。

認識日記頁（預設捕獲面）

左側點 Journals。每一天自動有一頁。在子彈後輸入第一塊：

Journals · 2026-10-28
- 今天開始建立第二大腦練習庫 - 靈感：發表會開場改用故事 #靈感 - TODO 匯入練習資料包

預期：三個子彈塊；標籤 #靈感 可點進標籤頁。

建立知識反射區頁

輸入 [[友誼]] 並進入該頁，寫下兩則與主題相關的塊（可用自己的話，勿整段抄書）。

Page · 友誼
- 友誼需要定期的小額「情感存款」，不是只在有事才聯絡 - 摘錄化用：真正的關心是記得對方在意的細節 - 回鏈：見 [[日記練習/2026-10-28]]

建立專案頁

建立 [[專案/產品發表]]，放入目標、待辦與素材連結。專案結束後停止更新，保留為歷史。

專案/產品發表
- 目標：30 分鐘完成故事型開場演練 - TODO 寫 90 秒開場白 - TODO 準備三張示意圖 - 相關：[[友誼]] 中「情感存款」可作開場隱喻

建立備忘頁

建立 [[備忘]]，放入低加工資訊，避免污染知識頁。

備忘
- 練習用虛擬地址：澳門範例街 12 號 - 常用連結：https://logseq.com - 食譜：燕麥粥＝燕麥+牛奶+堅果

雙向連結與區塊引用

在日記中輸入 (( 觸發塊引用，把「故事開場」那塊嵌到專案頁。修改原塊時，引用處同步——這就是避免複製漂移。

預期畫面：專案頁出現灰色引用塊，點擊可跳回原塊。

四類分揀演練

打開練習包中的 inbox-unsorted.md，把每條拖進或改寫到知識／專案／日記／備忘。目標：inbox 清空。

Query 儀表板

新建頁 [[儀表板]]，插入：

## 未完成 {{query (and (task TODO) [[專案/產品發表]])}} ## 靈感 {{query (and (page-tags #靈感))}}

預期：自動列出符合條件的塊。若語法隨版本差異，改用查詢建構器點選條件亦可。

一週回顧節奏

每週固定 20 分鐘：
① 掃日記未連結塊 → ② 補雙向連結 → ③ 封存已完成專案 → ④ 備忘頁去蕪存菁。
