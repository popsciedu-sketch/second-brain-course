Logseq 實作：從安裝到 Query

按下列步驟建立一個小型「第二大腦」練習庫。可下載練習資料包匯入或對照輸入。本頁已對照 Logseq 2.0（DB 版） 與 Logseq OG（檔案版）；課程後續步驟以可直接寫入 Markdown 資料夾的 OG 為主。

練習資料

路徑：assets/practice-data/ · 內含示例 Markdown 與 zip。清單見 DRIVE_UPLOAD_MANIFEST.md。

下載練習包（本地） Google Drive 練習包 Drive 資料夾

為什麼找不到「Open a local graph」？

若你剛用 Homebrew 裝的是 Logseq 2.0.x（App 路徑常是 /Applications/Logseq.app），介面上不會再出現「Open a local graph／Open a local directory」。這不是壞掉，而是產品線變了：

  • Logseq 2.0＝現行主線，資料存在內部資料庫（DB），不再直接把某個 Markdown 資料夾當「活 graph」打開。
  • Logseq OG 1.0＝刻意保留的檔案版支線，仍用本地 pages/、journals/ 等明文資料夾；本教材與助手代寫都依這條路最順。
本機若已在 ~/Documents/第二大腦 建好骨架（pages/、journals/、logseq/config.edn、assets/，預設頁含 inbox、知識、專案、備忘、週回），那是檔案型 graph。要用助手穩定寫入這些 .md，請開 Logseq OG，不要只開 2.0。

若堅持用 2.0 沿用現有資料夾

可以把檔案型骨架匯入成 DB 副本（之後主資料在 DB；Markdown 鏡像若有，也不是助手主要寫入目標）：

  1. 打開 Logseq 2.0
  2. 右上角 ⋯ → Import → File to DB graph
  3. 選 graph 根目錄（含 logseq/config.edn 的那層，例如 Documents/第二大腦）
  4. 為新的 DB graph 命名

截圖預留：⋯ → Import → File to DB graph標出選單路徑

本課建議：用 OG 打開本地資料夾

安裝 OG 後：All graphs → Open a local directory，指向 ~/Documents/第二大腦（或練習包解壓後的 graph 根目錄）。之後本頁「日記／四類／Query」步驟都在 OG 裡操作。

截圖預留：OG「Open a local directory」All graphs 畫面

下載並安裝（建議 OG）

macOS 可用 Homebrew 並存兩版：

  • 檔案版（本課主線）：brew install --cask logseq-og → App 名 Logseq-OG
  • DB 版（現行主線）：brew install --cask logseq → /Applications/Logseq.app

其他平台也可自 logseq.com 了解發行說明。本教程後續以本地 Markdown graph 資料夾為準，方便備份、傳承與助手代寫。

用 OG 打開（或新建）本地 Graph

在 Logseq-OG 選「Open a local directory」：

  • 已有骨架：選 ~/Documents/第二大腦（需含 logseq/config.edn）。
  • 從零練習：新建資料夾例如 SecondBrain-Practice，或解壓練習包後指向其 graph 根目錄。

這就是你的大腦皮層檔案根目錄——全是明文 Markdown／資料檔，利於繼承。若你開的是 2.0 而找不到此按鈕，請回到上一節「版本對照」。

截圖預留：系統選資料夾對話框選中 Documents/第二大腦

認識日記頁（預設捕獲面）

左側點 Journals。每一天自動有一頁。在子彈後輸入第一塊：

Journals · 2026-10-28
- 今天開始建立第二大腦練習庫 - 靈感：發表會開場改用故事 #靈感 - TODO 匯入練習資料包

預期：三個子彈塊；標籤 #靈感 可點進標籤頁。

建立知識反射區頁

輸入 [[友誼]] 並進入該頁，寫下兩則與主題相關的塊（可用自己的話，勿整段抄書）。

Page · 友誼
- 友誼需要定期的小額「情感存款」，不是只在有事才聯絡 - 摘錄化用：真正的關心是記得對方在意的細節 - 回鏈：見 [[日記練習/2026-10-28]]

建立專案頁

建立 [[專案/產品發表]]，放入目標、待辦與素材連結。專案結束後停止更新，保留為歷史。

專案/產品發表
- 目標：30 分鐘完成故事型開場演練 - TODO 寫 90 秒開場白 - TODO 準備三張示意圖 - 相關：[[友誼]] 中「情感存款」可作開場隱喻

建立備忘頁

建立 [[備忘]]，放入低加工資訊，避免污染知識頁。

備忘
- 練習用虛擬地址：澳門範例街 12 號 - 常用連結：https://logseq.com - 食譜：燕麥粥＝燕麥+牛奶+堅果

雙向連結與區塊引用

在日記中輸入 (( 觸發塊引用，把「故事開場」那塊嵌到專案頁。修改原塊時，引用處同步——這就是避免複製漂移。

預期畫面：專案頁出現灰色引用塊，點擊可跳回原塊。

四類分揀演練

打開練習包中的 inbox-unsorted.md，把每條拖進或改寫到知識／專案／日記／備忘。目標：inbox 清空。

Query 儀表板

新建頁 [[儀表板]]，插入：

## 未完成 {{query (and (task TODO) [[專案/產品發表]])}} ## 靈感 {{query (and (page-tags #靈感))}}

預期：自動列出符合條件的塊。若語法隨版本差異，改用查詢建構器點選條件亦可。

一週回顧節奏

每週固定 20 分鐘：
① 掃日記未連結塊 → ② 補雙向連結 → ③ 封存已完成專案 → ④ 備忘頁去蕪存菁。
