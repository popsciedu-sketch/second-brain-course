# 第二大腦 · Logseq 練習資料包

## 內容
- `inbox-unsorted.md`：12 條待分揀素材
- `pages/`：友誼、專案/產品發表、備忘、塊與神經元、儀表板
- `journals/`：兩天示例日記
- `queries/sample-queries.md`：Query 範例

## 使用方式
1. 安裝並開啟 Logseq，建立本地 graph（例如 `SecondBrain-Practice`）。
2. 可直接對照本資料在 Logseq 裡手打；或把 `pages/`、`journals/` 內容複製進 graph 對應資料夾後重新索引。
3. 先清空 `inbox-unsorted.md` 的分揀作業，再做雙鏈、區塊引用與 Query。

## 注意
所有地址、密碼、取件碼皆為虛構練習資料，請勿用於真實環境。
